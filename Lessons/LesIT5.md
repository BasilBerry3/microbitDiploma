## 💻 Содержание практической части

### Визуальные блоки (MakeCode)
- Блок `при старте` (on start) -> `радио задать группу 1`.
- Блок `при нажатии кнопки А` -> `радио передать число 1`.
- Блок `при нажатии кнопки B` -> `радио передать число 5` (имитация ложного/чужого сигнала).
- Блок `при получении радиособытия (receivedNumber)` -> `если receivedNumber >= 1 И receivedNumber <= 3` -> `показать значок Смайлик`, иначе -> `показать значок Череп`.

### 7. Домашнее задание:
- Модернизировать программу радио-чата: добавить отправку секретного текстового пароля по кнопке А+В, который будет проверяться составным условием на стороне получателя.

### Текстовый код (Python)
```python
radio.set_group(1)

def on_button_pressed_a():
    radio.send_number(1)
input.on_button_pressed(Button.A, on_button_pressed_a)

def on_button_pressed_b():
    radio.send_number(5)
input.on_button_pressed(Button.B, on_button_pressed_b)

def on_received_number(receivedNumber):
    if receivedNumber >= 1 and receivedNumber <= 3:
        basic.show_icon(IconNames.HAPPY)
    else:
        basic.show_icon(IconNames.SKULL)
radio.on_received_number(on_received_number)
```
