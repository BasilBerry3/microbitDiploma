## 💻 Содержание практической части

### Визуальные блоки (MakeCode)
- Цикл `постоянно` (forever) -> блок условия `если / иначе`.
- Логическое условие: `температура (ºC) < 22` (из категории **Ввод**).
- Ветка «Если» (холодно, организму некомфортно): `показать значок Грустный`.
- Ветка «Иначе» (температура в норме): `показать значок Веселый`.

### 7. Домашнее задание:
- Модернизировать программу климат-контроля: добавить третью ветку условий с помощью знака «плюс» (сложное ветвление), чтобы при температуре выше 28 градусов (перегрев) плата выводила предупреждающий символ или подавала звуковой сигнал.

### Текстовый код (Python)
```python
def on_forever():
    # Считываем текущую температуру с датчика процессора
    temp = input.temperature()
    # Проверяем нижнюю границу биологического комфорта
    if temp < 22:
        basic.show_icon(IconNames.SAD)
    else:
        basic.show_icon(IconNames.HAPPY)
basic.forever(on_forever)
```
