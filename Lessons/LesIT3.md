## 💻 Содержание практической части

### Визуальные блоки (MakeCode)
- Блок `при старте` (on start) -> `установить steps в 0`.
- Блок `при встряхивании` (on shake) -> `изменить steps на 1`.
- Блок `постоянно` (forever) -> `показать число` -> блок переменной `steps`.

### 7. Домашнее задание:
- Модернизировать алгоритм цифрового шагомера: добавить сброс счетчика шагов до нуля при одновременном нажатии на физические кнопки А и В.

### Текстовый код (Python)
```python
steps = 0

def on_gesture_shake():
    global steps
    steps += 1
input.on_gesture(Gesture.SHAKE, on_gesture_shake)

def on_forever():
    basic.show_number(steps)
basic.forever(on_forever)
```

* **4 уровень:** читать текстовый код на языке Python, изменять шаг счетчика и настраивать условия сброса параметров.
