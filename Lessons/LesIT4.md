## 💻 Содержание практической части

### Визуальные блоки (MakeCode)
- Блок `при старте` (on start) -> создать переменную `data_list` = `пустой массив`.
- Блок `при нажатии кнопки А` -> `в массив data_list добавить в конец значение` -> `температура (ºC)`. Показать иконку галочки (подтверждение записи).
- Блок `при нажатии кнопки Б` -> цикл `для каждого значения value из массива data_list` -> `показать число value`.

### 7. Домашнее задание:
- Доработать проект регистратора: добавить условие, чтобы при одновременном нажатии кнопок А и В массив полностью очищался, а на экран выводился символ крестика.

### Текстовый код (Python)
```python
data_list: List[number] = []

def on_button_pressed_a():
    data_list.append(input.temperature())
    basic.show_icon(IconNames.YES)
    basic.clear_screen()
input.on_button_pressed(Button.A, on_button_pressed_a)

def on_button_pressed_b():
    for value in data_list:
        basic.show_number(value)
input.on_button_pressed(Button.B, on_button_pressed_b)
```
