## 💻 Содержание практической части

### Визуальные блоки (MakeCode)
- Цикл `постоянно` (forever) -> создать переменную `light` = `аналоговое чтение: пин P0`.
- Условие: `Если light < 300` -> `показать значок Квадрат` (имитация включения лампы).
- Иначе -> `очистить экран`.

### 7. Домашнее задание:
- Модернизировать проект: превратить его в «Противоугонную систему». Если в закрытом ящике стола внезапно появляется свет (открытие крышки), плата должна начать издавать звуковой сигнал тревоги.

### Текстовый код (Python)
```python
def on_forever():
    # Считываем данные с внешнего фоторезистора на пине P0
    light = pins.analog_read_pin(AnalogPin.P0)
    # Если значение меньше порога (темно), включаем свет
    if light < 300:
        basic.show_icon(IconNames.SQUARE)
    else:
        basic.clear_screen()
basic.forever(on_forever)
```
