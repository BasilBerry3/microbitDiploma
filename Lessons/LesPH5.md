## 💻 Содержание практической части

### Визуальные блоки (MakeCode)
- Цикл `постоянно` (forever) -> создать переменную `force` = `магнитная сила (мкТл) сила`.
- Условие: `Если force > 200` -> `показать значок Алмаз` (обнаружение) и `играть звук`.
- Иначе -> `очистить экран`.

### 7. Домашнее задание:
- Модернизировать детектор: сделать «визуальную шкалу». Пусть количество горящих светодиодов на матрице зависит от близости магнита (чем ближе магнит — тем выше столбик на экране).

### Текстовый код (Python)
```python
def on_forever():
    # Считываем суммарную силу магнитного поля в микротеслах
    force = input.magnetic_force(Dimension.STRENGTH)
    # Если поле превышает фоновое (магнит рядом)
    if force > 200:
        basic.show_icon(IconNames.DIAMOND)
        music.play_tone(988, music.beat(BeatFraction.QUARTER))
    else:
        basic.clear_screen()
basic.forever(on_forever)
```
