## 💻 Содержание практической части

### Визуальные блоки (MakeCode)
- Цикл `постоянно` (forever) -> создать переменную `moisture` = `аналоговое чтение: пин P0`.
- Условие: `Если moisture < 400` -> `показать значок Грустный` (сигнал засухи), `играть тон Си на 1/4 такта`.
- `Иначе` -> `показать значок Веселый` (влажность в норме).

### 7. Домашнее задание:
- Модернизировать проект экологического мониторинга: превратить его в систему «Умный полив». Добавить подключение внешнего светодиода (или реле помпы) к пину P1, который будет автоматически включаться («поливать») только тогда, когда почва становится сухой.

### Текстовый код (Python)
```python
moisture = 0

def on_forever():
    global moisture
    # Считываем аналоговые данные с датчика влажности почвы на пине P0
    moisture = pins.analog_read_pin(AnalogPin.P0)
    # Если значение падает ниже порога влажности (почва пересохла)
    if moisture < 400:
        basic.show_icon(IconNames.SAD)
        music.play_tone(988, music.beat(BeatFraction.QUARTER))
    else:
        basic.show_icon(IconNames.HAPPY)
basic.forever(on_forever)
```
