## 💻 Содержание практической части

### Визуальные блоки (MakeCode)
- Цикл `постоянно` (forever).
- Блок `построить график-барометр для` -> значение `ускорение (mg) сила`.
- Параметр `до` -> значение `2048` (максимальная чувствительность сейсмографа).

### 7. Домашнее задание:
- Модернизировать сейсмограф: добавить переменную `max_vibration`, которая будет запоминать и выводить по кнопке А самое сильное колебание, зафиксированное за время эксперимента.

### Текстовый код (Python)
```python
def on_forever():
    # Считываем суммарный вектор ускорения и строим график на LED-матрице
    vibration = input.acceleration(Dimension.STRENGTH)
    led.plot_bar_graph(vibration, 2048)
basic.forever(on_forever)
```
